# Portafolio profesional — Francisco Ramos

Sitio estático, responsive y bilingüe para presentar experiencia en automatización, datos, QA, soporte TI y desarrollo web.

## Ver localmente

Abre `index.html` en un navegador o inicia un servidor local:

```bash
npx serve .
```

No requiere compilación ni dependencias.

## Contenido actual

- Perfil profesional y disponibilidad remota
- Seis proyectos con estado explícito: publicado, caso profesional, demo en preparación o próximo proyecto
- Habilidades agrupadas por especialidad
- Historia personal y preferencia de comunicación accesible
- Contacto directo por email, WhatsApp y GitHub
- Selector Español / English

## Antes de publicar

1. Agregar LinkedIn cuando el perfil esté preparado para reclutadores.
2. Incorporar un CV en inglés y enlazarlo desde la portada.
3. Reemplazar las representaciones gráficas por capturas anonimizadas cuando existan.
4. Revisar repositorios laborales e historial Git para eliminar RUT, nombres, correos, teléfonos, credenciales, tokens, URLs internas y documentos reales.
5. Publicar únicamente demos con usuarios y datasets ficticios.

## Proyectos recomendados

1. Sistema de gestión de turnos — proyecto público más completo.
2. Automatización Python / Selenium — caso profesional de alto valor, presentado sin datos internos.
3. Dashboard Power BI — demo con dataset ficticio.
4. Control de gestión documental — caso profesional con datos anonimizados.
5. QA Automation Demo — proyecto nuevo para evidenciar testing automatizado.
6. Sistema de soporte TI — proyecto principal futuro con Angular, Django y PostgreSQL.

## Privacidad

Los textos del sitio no incluyen datos laborales personales, credenciales ni enlaces a sistemas internos. Los proyectos futuros están marcados como tales para no confundirlos con entregables terminados.
